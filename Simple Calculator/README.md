## Project: Simple Calculator

### Description
A simple command-line calculator built using Python. It performs basic mathematical operations.

### Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Floor Division
- Error Handling
- Invalid Input Handling

### Technologies Used
- Python 3

### How to Run

```bash
python calculator.py
```
