## 📖 Description

**ATM Simulation** is a simple Python project that simulates the basic functionality of an ATM. It allows users to **enter a PIN, check their account balance, deposit money, withdraw money, and exit the program.**

---

## ✨ Features

| | Feature |
|---|---|
| 🔐 | Enter a 4-Digit PIN |
| 💰 | Check Account Balance |
| ➕ | Deposit Money |
| ➖ | Withdraw Money |
| 🚪 | Exit the ATM |
| ✅ | Input Validation |
| 📋 | Simple Menu-Driven Program |

## 🚀 How to Run

1. 📁 Open the project folder.
2. 💻 Open Terminal or Command Prompt.
3. ▶️ Run the following command:

```bash
python atm.py
```

---

## 🏦 Initial Account Details

| Detail | Value |
|---|---|
| 💵 Initial Balance | `50000` |
| 🔑 PIN | Any valid 4-digit number (`1000–9999`) |

---

## 🎛️ Available Options

| Option | Action |
|:---:|---|
| `1` | 💰 Check Balance |
| `2` | ➕ Deposit Money |
| `3` | ➖ Withdraw Money |
| `4` | 🚪 Exit |

---

## 🛡️ Validations

- ✅ PIN must be a valid 4-digit number.
- ✅ Deposit amount must be greater than 0.
- ✅ Withdrawal amount must not exceed the available balance.
- ✅ Invalid menu options are handled.
